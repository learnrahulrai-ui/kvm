Lottery accounting
GOAL: Record the CPU time of eligible programs and return a consistent snapshot.
CAUSE: eligible task -> ticket pool -> winner -> tick count
DATA: pstat.inuse | pstat.tickets | pstat.pid | pstat.ticks
CORRECTION: double count -> biased draw -> one eligible scan -> valid draw
INTERVIEWER TRAP: forked child -> inherited ticket -> pool sum -> wrong share
MANUAL CALCULATION: A parent with 10 tickets and a child inheriting 10 contributes 20 tickets when both are runnable, not 10.
EVIDENCE STATUS: Instructor identifies ticket double-counting as a known implementation failure mode; not a verified incident.
