This is a REAL out-of-tree Linux module, not the finished UIUC MP3.
Host kernel module source: mp3_profiler.c. Exports /proc/mp3/status as a READ-ONLY entry that returns NOT_IMPLEMENTED.
Student retains PID registration, unregister, /proc parsing, minor/major fault counting, CPU-time sampling, work queue, synchronization, vmalloc buffer, mmap, and cleanup logic.
Compile on your own machine:
  make -C assignments/19-uiuc-cs423-mp3/kernel_module
KDIR automatically uses /lib/modules/$(uname -r)/build, so a pasted kernel version is NOT assumed.
To compile against a specific installed headers tree without running or loading:
  make KDIR=/usr/src/linux-headers-6.14.0-37-generic
THIS DOES NOT INSTRUCT YOU TO RUN insmod, rmmod, or change system state.
Independent compile proof: tested using /usr/src/linux-headers-6.12.107+deb13-amd64; kbuild produced mp3_profiler.ko; readelf confirmed .debug_info.
No access to the user's laptop or its live kernel is implied by this build.
