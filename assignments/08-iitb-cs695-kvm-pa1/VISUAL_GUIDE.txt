KVM guest execution
GOAL: Back guest physical memory with host memory and handle exits without losing ownership.
CAUSE: guest RAM -> memslot -> vCPU -> VM exit
DATA: slot.gpa | slot.hva | slot.bytes | run.exit
CORRECTION: premature free -> stale map -> notifier barrier -> safe release
INTERVIEWER TRAP: host pointer -> guest address -> same bits -> wrong domain
MANUAL CALCULATION: A 2 MiB registered slot covers 512 4 KiB guest pages, but that number does not identify 512 physical frames before allocation.
EVIDENCE STATUS: Verified KVM MMU-notifier release race, 2017, in upstream KVM.
PRIMARY/RELEVANT SOURCE: https://lkml.iu.edu/1704.3/00256.html
