Frame eviction and swap
GOAL: Choose a reclaimable frame while tracking its reference, dirtiness and swap destination.
CAUSE: fault -> frame lookup -> clock scan -> swap
DATA: frame.owner | frame.access | frame.dirty | swap.slot
CORRECTION: pinned frame -> evict early -> pin checked -> safe eviction
INTERVIEWER TRAP: access bit -> DMA pin -> clock choice -> wrong victim
MANUAL CALCULATION: Clock search uses reference bits and a moving hand; smallest numeric frame index is not the victim rule.
EVIDENCE STATUS: Linux upstream COW/pin race is a related real lifetime failure, not an identified Pintos bug.
PRIMARY/RELEVANT SOURCE: https://lkml.iu.edu/hypermail/linux/kernel/2111.1/07621.html
