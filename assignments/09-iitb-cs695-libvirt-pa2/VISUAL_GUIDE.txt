VM autoscaling
GOAL: Add a serving VM only after measured demand justifies it and routing can use it.
CAUSE: requests -> CPU sample -> new VM -> traffic
DATA: domain.state | domain.cpu | domain.memory | ready flag
CORRECTION: created VM -> premature route -> ready VM -> safe route
INTERVIEWER TRAP: running process -> not ready -> routing -> lost service
MANUAL CALCULATION: Two active domains do not prove two ready application endpoints; domain running and application ready are different predicates.
EVIDENCE STATUS: No exact assignment bug verified; readiness ordering is a constructed failure case.
PRIMARY/RELEVANT SOURCE: https://libvirt.org/html/libvirt-libvirt-domain.html
