Copy-on-write fork
GOAL: Give parent and child separate writable content only when a write requires separation.
CAUSE: fork -> shared page -> write fault -> private page
DATA: page.refcount | pte.flags | page.data | owner.map
CORRECTION: pinned page -> wrong COW -> ownership check -> correct view
INTERVIEWER TRAP: read pin -> write fault -> new frame -> stale device
MANUAL CALCULATION: Parent and child initially share one 4096-byte frame; after child writes, two frames carry different bytes and references change.
EVIDENCE STATUS: Verified Linux COW bugs arise when pages pinned for I/O diverge from a new COW mapping.
PRIMARY/RELEVANT SOURCE: https://lkml.iu.edu/hypermail/linux/kernel/2111.1/07621.html
