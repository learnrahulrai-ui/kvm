Minimal KVM machine
GOAL: Start guest real-mode instructions, decode an I/O exit and resume after fulfilling it.
CAUSE: guest bytes -> KVM run -> I/O exit -> host output
DATA: guest.regs | run.exit | io.port | memory.slot
CORRECTION: exit pending -> save too soon -> reenter guest -> exit complete
INTERVIEWER TRAP: guest writes -> IO exit -> completion -> reentry
MANUAL CALCULATION: A guest memory slot with 4096 bytes contains one base page; the I/O exit's data buffer is separate from that slot.
EVIDENCE STATUS: KVM API documents asynchronous userspace-exit completion on KVM_RUN reentry; not a course bug.
PRIMARY/RELEVANT SOURCE: https://www.kernel.org/doc/html/latest/virt/kvm/api.html
