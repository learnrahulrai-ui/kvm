AMD SVM guest entry
GOAL: Keep VMCB and VMSA state valid while another processor initiates protected guest teardown.
CAUSE: VMCB -> VMRUN -> guest vCPU -> VM exit
DATA: vmcb.control | vmcb.state | nested.page | exit.code
CORRECTION: destroy pending -> VMRUN race -> request wait -> safe teardown
