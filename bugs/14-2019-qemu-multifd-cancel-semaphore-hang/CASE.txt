CORE FAILURE, NOT AN ERROR-RETURN EXERCISE:
Migration source cancellation and multifd receive worker teardown lacked a completion/wake path; destination could wait on a semaphore for work that the canceled source would never provide. The v4.1.0-rc2 fix series covers distinct endless loops and destination deadlock. Individual patch diff not yet verified, so exact wake primitive beyond this must be derived by opening source.

QMP migrate starts -> RAM sent on multiple channels -> QMP migrate_cancel -> sender quits -> receiver still waits on migration semaphore -> destination hangs
