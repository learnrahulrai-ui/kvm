END-USER FAILURE: QEMU skips a source zero page whose destination still contains firmware bytes
CORE FAILURE, NOT AN ERROR-RETURN EXERCISE:
Optimization assumes zero on source implies zero already at destination. BIOS versions or machine setup can initialize a destination page with nonzero contents, so not transmitting the source zero contents leaves stale destination bytes.
CALL / DATA / STATE PATH:
source page all zero -> ram_save_block skips sending during bulk stage -> destination preinitialized by different BIOS -> destination page still nonzero -> guest resumes with incorrect memory

FAILURE SIGNAL AND CONTROL:
